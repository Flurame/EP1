Райская мебель — Система управления мебельным производством
Проект разработан в рамках учебной практики. Система автоматизирует учет продукции, управление цехами и расчет необходимых материалов с учетом коэффициентов брака.

🚀 Запуск проекта
1. Клонировать репозиторий:
bash
git clone [(https://github.com/Flurame/EP1)]
cd [УКАЖИТЕ_НАЗВАНИЕ_ПАПКИ_РЕПОЗИТОРИЯ]
2. Настроить виртуальное окружение:
bash
python -m venv venv
source venv/bin/activate  # Для Windows: venv\Scripts\activate
pip install -r requirements.txt
3. Настройка базы данных:
Создайте БД в PostgreSQL (укажите название БД)

В файле config.py укажите свои данные для подключения:

Хост БД

Имя пользователя

Пароль

Название БД

Выполните миграции и импорт данных:

bash
python create_db.py
python import_data.py
4. Запуск сервера:
bash
python app.py
Приложение доступно по адресу: http://127.0.0.1:5000
